word_tokenize Function

Import Statement: from nltk.tokenize import word_tokenize
💡 What it is & Does:

Splits sentences into individual discrete word and punctuation tokens. It handles contractions and isolates punctuation.

🛠️ How to use it (Python): 
from nltk.tokenize import word_tokenize

text = "Natural Language Processing with NLTK is fun!"
tokens = word_tokenize(text)
print(tokens)
# Output: ['Natural', 'Language', 'Processing', 'with', 'NLTK', 'is', 'fun', '!']

How to Install NLTK & Download Corpora

Set up Python NLTK and fetch tokenizers, dictionaries, and language models.

Terminal (CLI) Step 1: Install Python Package 
# Install NLTK via pip
pip install nltk

# Optional: verify installation in terminal
python -c "import nltk; print(nltk.__version__)"
💡 Use Case: Installs the core NLTK algorithms and token parsing engine into your active virtual environment.
Python Script Step 2: Download Required Corpora & Models 
import nltk

# 1. Download Punkt Tokenizer Models (Required for sent_tokenize & word_tokenize)
nltk.download('punkt')

# 2. Download Stopwords Corpus (Required for filtering English stopwords)
nltk.download('stopwords')

# 3. Download WordNet (Required for Lemmatization)
nltk.download('wordnet')

# 4. Download Averaged Perceptron Tagger (Required for POS Tagging)
nltk.download('averaged_perceptron_tagger')

# Optional: Download popular packages in one command
# nltk.download('popular')
💡 Why this is needed: NLTK is modular to keep the base library lightweight. Large corpora and pretrained token boundary models are downloaded on-demand when required.
02

Tokenization Functions

Slicing paragraphs into sentences (Documents) and words (Tokens).

nltk.tokenize sent_tokenize() & word_tokenize() 
from nltk.tokenize import sent_tokenize, word_tokenize

paragraph = "NLP is fun. Computers read human words using tokens!"

# 1. Sentence Tokenization (Corpus -> Documents)
sentences = sent_tokenize(paragraph)
print("Sentences:", sentences)
# Output: ['NLP is fun.', "Computers read human words using tokens!"]

# 2. Word Tokenization (Document -> Tokens)
words = word_tokenize(sentences[0])
print("Words:", words)
# Output: ['NLP', 'is', 'fun', '.']
🎯 Real-world Use Case: Text preprocessing for search engines, chatbot intent extractors, and NLP transformers where unstructured paragraphs must be split into clean token arrays.
nltk.tokenize RegexpTokenizer & wordpunct_tokenize() 
from nltk.tokenize import RegexpTokenizer, wordpunct_tokenize

text = "Deep learning, ML, & AI: revolutionize tech in 2026!"

# Extract words only (strip all punctuation symbols)
tokenizer = RegexpTokenizer(r'\w+')
clean_words = tokenizer.tokenize(text)
print("Words without punctuation:", clean_words)
# Output: ['Deep', 'learning', 'ML', 'AI', 'revolutionize', 'tech', 'in', '2026']
🎯 Real-world Use Case: Cleaning noisy user comments, Twitter/X posts, or social media text where punctuation must be excluded before building word frequency dictionaries.

Corpora & Pre-built Datasets (nltk.corpus)

Accessing benchmark paragraphs and classic text collections.

nltk.corpus Accessing Built-in Corpora 
import nltk
from nltk.corpus import gutenberg, brown

# Download Gutenberg corpus if not downloaded
nltk.download('gutenberg')

# 1. List files in Gutenberg corpus
print(gutenberg.fileids()[:3])
# Output: ['austen-emma.txt', 'austen-persuasion.txt', 'austen-sense.txt']

# 2. Access raw text, sentences (documents), or words (tokens)
emma_words = gutenberg.words('austen-emma.txt')
emma_sents = gutenberg.sents('austen-emma.txt')

print("Total Tokens in Emma:", len(emma_words))
print("Total Sentences (Documents):", len(emma_sents))
🎯 Real-world Use Case: Training benchmark language models, testing semantic analysis algorithms, and linguistically comparing classical literature across centuries.
04

Stopwords Removal

Eliminating low-information words like "the", "is", "at", "which".

nltk.corpus.stopwords Filtering English Stopwords 
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

# Load English stopwords set
stop_words = set(stopwords.words('english'))

sentence = "This is a great study website for learning NLP with Python."
tokens = word_tokenize(sentence)

# Filter tokens
filtered_tokens = [w for w in tokens if w.lower() not in stop_words and w.isalnum()]

print("Original Tokens (Count: {}):".format(len(tokens)), tokens)
print("Filtered Tokens (Count: {}):".format(len(filtered_tokens)), filtered_tokens)
# Output: ['great', 'study', 'website', 'learning', 'NLP', 'Python']
🎯 Real-world Use Case: Spam detection, document search indexing, and keyword extraction where non-informative filler words add noise to classification algorithms.
05

Stemming & Lemmatization

Reducing inflected and derived words to their root or base vocabulary form.

nltk.stem PorterStemmer vs WordNetLemmatizer 
from nltk.stem import PorterStemmer, WordNetLemmatizer

ps = PorterStemmer()
lemmatizer = WordNetLemmatizer()

words = ["running", "runs", "ran", "studies", "studying", "better"]

print("--- STEMMING (Heuristic Suffix Chopping) ---")
for w in words:
    print(f"{w:10} -> {ps.stem(w)}")
# running -> run, studies -> studi, better -> better

print("\n--- LEMMATIZATION (Dictionary Root with POS) ---")
for w in words:
    print(f"{w:10} -> {lemmatizer.lemmatize(w, pos='v')}")
# running -> run, studies -> study, better -> good (if pos='a')
🎯 Real-world Use Case: Search query matching (e.g. searching "studying" matches documents containing "study") and building normalized vocabulary sets in information retrieval.
06

Frequency Distribution (FreqDist)

Tallying word frequencies and discovering the vocabulary of a corpus.

nltk.probability.FreqDist Count Unique Words & Discover Top Keywords 
from nltk.probability import FreqDist
from nltk.tokenize import word_tokenize

text = "NLP helps computers learn. NLP processes language. Computers learn words."
tokens = [w.lower() for w in word_tokenize(text) if w.isalnum()]

# Build Frequency Distribution
fdist = FreqDist(tokens)

# 1. Total tokens vs Unique Vocabulary Size
print("Total Word Tokens:", fdist.N())          # Output: 11
print("Unique Vocabulary Size:", fdist.B())     # Output: 6

# 2. Get 3 Most Common Words
print("Top 3 Words:", fdist.most_common(3))
# Output: [('nlp', 2), ('computers', 2), ('learn', 2)]

# 3. Frequency of a specific word
print("Frequency of 'nlp':", fdist['nlp'])      # Output: 2
🎯 Real-world Use Case: Word clouds, topic modeling, TF-IDF feature extraction, and identifying domain-specific terminology in legal or medical documents.
07

Part-of-Speech (POS) Tagging & NER

Labeling words as nouns, verbs, adjectives, and identifying entity names.

nltk.tag & nltk.chunk pos_tag() and ne_chunk() 
import nltk
from nltk.tokenize import word_tokenize

sentence = "Sundar Pichai leads Google in Mountain View."
tokens = word_tokenize(sentence)

# 1. Part-of-Speech Tagging
tagged = nltk.pos_tag(tokens)
print("POS Tags:", tagged)
# Output: [('Sundar', 'NNP'), ('Pichai', 'NNP'), ('leads', 'VBZ'), ('Google', 'NNP'), ...]
# NNP = Proper Noun, VBZ = 3rd person singular present verb

# 2. Named Entity Recognition (Extract Names, Organizations, Locations)
nltk.download('maxent_ne_chunker')
nltk.download('words')
tree = nltk.ne_chunk(tagged)
print("Named Entity Tree:\n", tree)
🎯 Real-world Use Case: Customer support ticket routing, extracting company/person names from financial news, and resume/CV parsing.
