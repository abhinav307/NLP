🏛️ NLTK Library Quick Directory

Click any module below to activate that tool in the visual studio above:

✂️ nltk.tokenize Tokenization

Breaks continuous text into structured sentences and word token chips.

word_tokenize() sent_tokenize()
🛑 nltk.corpus.stopwords Noise Removal

Eliminates high-frequency filler words (is, the, with) to focus on key concepts.

stopwords.words('english')
🌱 nltk.stem Stemming

Chops off prefixes and suffixes using rule-based heuristics (Porter & Snowball).

PorterStemmer SnowballStemmer
📚 nltk.stem.wordnet Dictionary Roots

Consults WordNet dictionary to extract true grammatical root words (better ➔ good).

WordNetLemmatizer
📊 nltk.probability Keyword Frequency

Counts word occurrences and ranks top keywords with visual frequency bars.

FreqDist()
