💡 Why Lemmatization? Primary Real-World Use Cases (From Notebook)

1. Question & Answering (Q&A)

Matches user queries like "Where was he running?" to facts containing "he runs" by resolving both to the lemma run.

2. Conversational Chatbots

Understands customer intent regardless of grammatical tense, pluralization, or irregular comparative forms (better ➔ good).

3. Text Summarization

Deduplicates diverse sentence clauses so frequency algorithms accurately tally genuine conceptual weight without distortion.

📖 The 4 Core Part-of-Speech (POS) Tags in NLTK

POS Code: 'n' Default Tag

Noun (n)

Handles pluralization and irregular plurals. If no POS argument is passed, WordNet defaults to Noun!

lemmatize("wolves", pos='n') ➔ "wolf"
lemmatize("corpora", pos='n') ➔ "corpus"
POS Code: 'v' Action Roots

Verb (v)

Restores inflected past tense, gerunds, and third-person conjugations into base infinitives.

lemmatize("going", pos='v') ➔ "go"
lemmatize("goes", pos='v') ➔ "go"
lemmatize("ran", pos='v') ➔ "run"
POS Code: 'a' Descriptors

Adjective (a)

Reduces comparative and superlative adjective degrees to their positive base root.

lemmatize("better", pos='a') ➔ "good"
lemmatize("happier", pos='a') ➔ "happy"
lemmatize("worst", pos='a') ➔ "bad"
POS Code: 'r' Modifiers

Adverb (r)

Handles irregular adverbs like better in an adverbial context, converting to well.

lemmatize("better", pos='r') ➔ "well"
lemmatize("fairly", pos='r') ➔ "fairly"
Python 3.12 NLTK Source: Lemmatization- Text Processing.ipynb 
from nltk.stem import WordNetLemmatizer

lemmatizer = WordNetLemmatizer()

# Demonstration of POS Tags on "going":
print("going (noun)      ----->", lemmatizer.lemmatize("going", pos='n')) # going
print("going (verb)      ----->", lemmatizer.lemmatize("going", pos='v')) # go
print("going (adjective) ----->", lemmatizer.lemmatize("going", pos='a')) # going
print("going (adverb)    ----->", lemmatizer.lemmatize("going", pos='r')) # going

# Irregular forms:
print("goes   (verb)     ----->", lemmatizer.lemmatize("goes", pos='v'))   # go
print("better (adjective)----->", lemmatizer.lemmatize("better", pos='a')) # good
print("better (adverb)   ----->", lemmatizer.lemmatize("better", pos='r')) # well
print("wolves (noun)     ----->", lemmatizer.lemmatize("wolves", pos='n')) # wolf
