📖 Stemmer Types Deep Dive (From Your Notebook)

Type 1: Heuristic Algorithm PorterStemmer

Classic 1980 Rule-Based Suffix Stripping

Uses a sequence of hand-crafted cascading rules to chop off common English suffixes (-ing, -ed, -ly, -es, -s).

Where it succeeds:
stemming.stem('sitting') ➔ 'sit' 😘
Where it over-stems:
stemming.stem('congratulations') ➔ 'congratul' 😒
from nltk.stem import PorterStemmer
stemming = PorterStemmer()
for i in words:
    print(i + " -----> " + stemming.stem(i))
Type 2: Customizable Regex RegexpStemmer(pattern, min=4)

User-Defined Regex Rules with Length Guard (min=4)

Allows full custom control over what suffixes to strip using regular expressions like 'ing$|s$|e$|able$'. The min=4 parameter prevents chopping short words.

Clean Stripping:
eating ➔ 'eat'
cats ➔ 'cat'
readable ➔ 'read'
min=4 Threshold:
see (len 3) ➔ 'see' (protected)
runs (len 4) ➔ 'run'
Edge Cases:
love ➔ 'lov' 😒
table ➔ 't' 😒
sing ➔ 's' 😒
from nltk.stem import RegexpStemmer
rex_stemmer = RegexpStemmer('ing$|s$|e$|able$', min=4)
print(rex_stemmer.stem('eating')) # 'eat'
print(rex_stemmer.stem('readable')) # 'read'
Type 3: Modern Algorithm SnowballStemmer ('english')

Porter2: Faster, Modern & Multi-Language

Developed by Martin Porter to address known flaws in the original 1980 algorithm. Handles English irregularities better and supports 15+ languages.

Where Snowball wins over Porter:
  • fairly ➔ Porter: 'fairli' vs. Snowball: 'fair' ✅
  • sportingly ➔ Porter: 'sportingli' vs. Snowball: 'sport' ✅
  • historical ➔ Porter: 'histor' vs. Snowball: 'histori' ✅
from nltk.stem import SnowballStemmer
snow_ball = SnowballStemmer('english')
print(snow_ball.stem("fairly")) # 'fair'
print(snow_ball.stem("sportingly")) # 'sport'
